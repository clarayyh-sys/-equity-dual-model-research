# 股票模型构建（本地）

## 目标
构建一个可回测、可复现实验的股票量化模型工程：数据 → 特征 → 标签/目标 → 训练 → 回测 → 报告。

## 你需要先确认的 6 件事
1. **市场**：A股 / 美股 / 港股？（你提到“股票模型”，默认我按 **A股** 预设）
2. **频率**：日频 / 分钟 / Tick？
3. **策略形态**：选股（横截面）/ 择时（单标的）/ 多因子打分？
4. **持有周期**：1天/5天/20天…
5. **交易约束**：手续费、滑点、涨跌停、停牌、ST、最小成交额、换手限制等
6. **数据来源**：AkShare（免费）、TuShare（需token）、券商导出CSV、你已有本地数据？

## 工程结构
- `data/raw`：原始数据（不要手改）
- `data/processed`：清洗后的数据/特征
- `src/`：核心代码
- `configs/`：配置文件
- `reports/`：回测结果、图表

## 快速开始（建议）
- 先用 **日频 + 横截面选股** 跑通一条最小闭环：
  - 目标：预测未来 N 日收益（回归）或是否跑赢基准（分类）
  - 模型：LightGBM / XGBoost
  - 回测：按TopK持仓、每期再平衡
